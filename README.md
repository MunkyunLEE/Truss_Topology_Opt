# Grid Topology Optimization

격자 기반 3D/2D 트러스 위상최적화 웹 툴입니다. 노드 사이를 잇는 후보 부재 집합(ground structure)을 만들고, 그 위에서 소성 LP로 최소 체적 트러스 배치를 찾습니다. 지지·하중·장애물은 박스 영역으로 지정합니다.

- **설치·서버 불필요**: 정적 웹페이지입니다. 계산은 브라우저 안(Web Worker + HiGHS WebAssembly)에서 이루어지고, 입력이나 결과가 외부로 전송되지 않습니다.
- **필요한 것**: 최신 브라우저(Chrome, Edge, Firefox, Safari). 3D 뷰(three.js), HiGHS 솔버(jsDelivr), 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- **수식·알고리즘 설명**: [`docs/formulation.html`](docs/formulation.html)

## 실행

| 방법 | 설명 |
|---|---|
| 로컬 (오프라인) | `npm install` 후 `python3 src/build.py` → 생성된 `standalone.html`(약 5 MB, 솔버 내장)을 더블클릭합니다. `index.html`은 `src/core.js`를 불러오므로 파일로 직접 열면 동작하지 않습니다. |

## 주요 기능

- **3D / 2D**: 셀 수 nx·ny·nz 중 한 축을 0으로 두면 해당 평면의 2D 트러스로 풉니다.
- **연결 범위**:
  - 전 연결(기본): 중간에 노드가 없는 모든 노드 쌍을 후보로 둡니다. 부재 추가법으로 필요한 부재만 LP에 넣습니다.
  - 1셀 이내: 인접한 격자점끼리만 연결합니다.
- **목적 함수**:
  - 최소 단면(기본): 단면 제한 없이 최적화한 뒤, A_min보다 가는 부재를 A_min으로 올리고 다시 최적화합니다. 이어서 빼도 되는 가는 부재를 정리합니다(부재 수가 늘지 않고 체적이 줄거나, 허용치 안에서 부재 수가 줄 때). 단면 카탈로그를 주면 최종 단면을 규격값으로 올림합니다.
  - 단면 비율 제한(이전 방식): 하한 미만 부재 제거를 먼저 시도합니다.
  - 체적 최소: 단면에 제한을 두지 않습니다.
- **분포하중**: 하중 영역의 하중은 부담 길이·면적 가중으로 노드에 나눕니다(선 끝 ½, 면 모서리 ¼). 위에 얹는 패널이 노드로 하중을 전달한다고 봅니다.
- **실무 조건**:
  - X 교차 금지(삼각형 가새만), 장거리 부재 교차점 절점화
  - 대칭 자동 감지
  - 지지 영역별 반력 분담
  - 다중 하중 케이스
- **안정성**:
  - 평형행렬 SVD로 자유도를 판정합니다(m = 0이 목표).
  - 강체 삼각형 면 기준으로 접힘을 분석합니다.
  - 잠금 부재를 자동으로 추가합니다.
- **좌굴**: 오일러 좌굴(원형 중공관 또는 중실 단면, 안전율 γ)을 검토하고, 초과하면 횡보강하거나 단면을 키웁니다. 이어서 선형 해석 기반 단면 보정(FSD)을 수행합니다.
- **기하 최적화 (선택)**: 자유 노드를 격자 밖 연속 위치로 옮겨 체적을 더 줄입니다.
- **최대 하중 배수 λ**: 결과 구조에 대해 첫 부재 한계(선형 해석)와 붕괴(재분배 허용 LP) 두 값을 냅니다. 좌굴 안전율 γ 없이 계산하고, 지배 부재를 노란색으로 표시합니다.
- **내보내기**: Abaqus `.inp`(T3D2, ELSET MAIN/BRACING), 부재 CSV, 결과 JSON, 문제 JSON.

## 조작법

### 화면 구성
- **왼쪽 패널**: 격자, 재료, 영역 조건, 추가 노드, 목적 함수, 좌굴·보강, 최적화 옵션, 문제 파일(JSON)
- **가운데 뷰포트**: 3D 모델과 결과
- **아래쪽**: 결과 통계와 실행 로그
- **오른쪽 위 버튼**: **최적화 실행**

### 시점
| 동작 | 조작 |
|---|---|
| 회전 | 왼쪽 드래그 (3D 뷰에서만) |
| 이동 | 오른쪽 드래그 |
| 확대·축소 | 마우스 휠 |
| 정면 뷰 | `3D` `XY` `XZ` `YZ` 버튼 |
| 전체 보기 | `시점 맞춤` |

### 영역(지지·하중·장애물) 그리기
1. 뷰포트 상단에서 `지지` / `하중` / `장애물` 중 하나를 누릅니다.
2. 그릴 평면을 고릅니다. `XY`·`XZ`·`YZ` 뷰를 선택하고, 그 평면의 높이를 `− / +` 버튼이나 숫자 입력으로 정합니다.
3. 뷰포트에서 드래그하면 사각형 영역이 생깁니다. 클릭만 하면 한 점짜리 영역이 생깁니다.
4. 만든 박스를 클릭해 선택하고, 면 핸들을 끌어 두께를 줍니다(extrude).
5. 마무리:
   - 같은 버튼을 다시 누르거나 `Esc`를 누르면 그리기가 끝납니다.
   - 선택한 박스는 `Delete`로 지웁니다.
   - 스냅(`격자` / `½ 격자` / `자유`)으로 좌표를 맞춥니다.

왼쪽 패널의 영역 카드에서도 min/max 좌표, 구속 방향(x, y, z), 하중 벡터, 하중 케이스 번호를 직접 입력할 수 있습니다. 박스 안(경계 포함)에 있는 노드에 조건이 걸립니다. "면 보간 노드"를 켜면 박스 면이 격자선과 만나는 위치에 노드가 추가됩니다.

### 실행과 결과 보기
1. 목적 함수와 옵션을 고른 뒤 **최적화 실행**을 누릅니다. 진행 상황과 단계별 소요 시간은 로그에 나옵니다.
2. 뷰포트 토글로 표시할 항목을 고릅니다: 격자 노드, 후보 부재, 영역, 결과, 강접합 후보, 접힘 분석, 처짐(배율 슬라이더, 하중 케이스 선택).
3. 부재 색상의 의미:

| 색 | 의미 |
|---|---|
| 빨강 | 인장 |
| 파랑 | 압축 |
| 올리브 | 잠금·횡보강 |
| 노랑 | 최대 하중 배수를 결정한 부재 |
| 보라 점 | 남은 메커니즘 노드 |

   부재 굵기는 단면적에 비례합니다.
4. 통계 아래 내보내기 버튼으로 Abaqus `.inp`, CSV, JSON을 저장합니다.

입력을 바꾸면 "입력이 바뀌었습니다" 표시가 뜹니다. 다시 실행해 주세요.

### 문제 저장·불러오기 (JSON)
- **저장**: `문제 JSON 보기·저장`
- **불러오기**: 다음 셋 중 하나를 씁니다.
  - 파일 선택
  - 뷰포트에 JSON 파일 끌어다 놓기
  - `붙여넣기로 불러오기`
- **예제**: [`examples/`](examples/)에 2D 대칭 보와 3D 외팔보가 있습니다.

```json
{
  "grid": { "origin": [0,0,0], "h": 100, "nx": 10, "ny": 0, "nz": 4 },
  "material": { "E": 205000, "nu": 0.3, "sigmaT": 235, "sigmaC": 235 },
  "regions": [
    { "type": "support", "min": [0,0,0],    "max": [0,0,0],      "fix": [1,1,1] },
    { "type": "support", "min": [1000,0,0], "max": [1000,0,0],   "fix": [1,1,1] },
    { "type": "load",    "min": [0,0,400],  "max": [1000,0,400], "F": [0,0,-10000], "case": 1 }
  ],
  "extraNodes": [],
  "options": { "objective": "roundup" }
}
```
단위는 mm, N, MPa입니다. `F`는 영역 전체 하중이며, 영역 안 노드에 부담 길이·면적 비율로 나눠 줍니다. 생략한 옵션에는 기본값이 쓰입니다.

## 개발

```
index.html     웹 UI + 3D 뷰 + Web Worker (솔버는 src/core.js, HiGHS는 jsDelivr에서 로드)
src/core.js    솔버 (ground structure, LP/MILP, 대칭, 부재 추가, 안정화, 좌굴, FSD, 하중 배수, .inp)
src/build.py   오프라인용 standalone.html 생성 (core.js + HiGHS JS·WASM 내장)
docs/          수식 정리 문서
examples/      예제 문제
```

`index.html`과 `src/core.js`를 직접 고치면 바로 반영됩니다(빌드 불필요). `core.js`는 Node에서도 쓸 수 있습니다: `require('./src/core.js').run(await require('highs')(), problem, console.log)`.

## 참고
- 핀접합 트러스만 지원합니다. 빔(강접합) 요소는 아직 없습니다.
- 결과는 개념 설계용입니다. 실제 설계에는 내보낸 `.inp`로 상세 해석(접합부, 국부 좌굴, 하중 조합)을 별도로 수행해야 합니다.
- 주요 참고문헌: Dorn et al. (1964), Gilbert & Tyas (2003), Zegard & Paulino (2014, 2015), He & Gilbert (2015), Pellegrino (1993). 전체 목록은 `docs/formulation.html`에 있습니다.
